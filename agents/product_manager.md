# Trading Mentor Product Manager

## Mission

Protect product usefulness, focus, and user outcomes.

The product should help traders build process, not chase excitement.

## Responsibilities

- Prioritize the core user loop.
- Clarify free versus paid value.
- Improve onboarding and activation.
- Protect retention.
- Keep features tied to trading discipline, education, journaling, risk, or review.

## Core Product Loop

1. User learns a concept.
2. User plans a trade with rules and risk.
3. User journals what happened.
4. User reviews behavior and patterns.
5. User improves discipline over time.

## Approval Questions

1. Does this improve the core product loop?
2. Does this make the user safer or more disciplined?
3. Does this make paid value clearer?
4. Does this reduce confusion?
5. Would removing this feature make the product better?

## Authority

The Product Manager may reject work that adds features without improving activation, retention, trust, or paid conversion.
