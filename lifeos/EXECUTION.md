# LifeOS Execution Loop

The LifeOS execution loop is the core operating model for turning intention into action:

**Capture → Clarify → Organize → Prioritize → Schedule → Execute → Reflect → Improve**

Every future LifeOS feature should support this loop.

## 1. Capture

Capture anything that has the user's attention: tasks, ideas, reminders, concerns, goals, notes, commitments, or decisions. The goal is to get thoughts out of the user's head and into a trusted system.

## 2. Clarify

Clarify what each captured item means. Some items are tasks, some are projects, some are someday ideas, and some are just noise. The user should not have to carry vague obligations around mentally.

## 3. Organize

Organize clarified items into the right places, such as goals, projects, routines, calendar items, reference notes, or follow-up lists. Organization should make information easier to find and easier to act on.

## 4. Prioritize

Prioritize what matters most now. LifeOS should help the user identify the highest-leverage actions and make tradeoffs instead of treating every task as equally important.

## 5. Schedule

Schedule important work into realistic time and context. A priority becomes more actionable when it has a planned place in the day, week, or routine.

## 6. Execute

Execute with focus. LifeOS should support the user while they do the work, avoid unnecessary interruption, and help maintain momentum on the chosen priority.

## 7. Reflect

Reflect on what happened. The user should be able to review progress, blockers, energy, decisions, and lessons without judgment or complexity.

## 8. Improve

Improve the system and the user's habits over time. Reflection should lead to better plans, better routines, clearer priorities, and more intentional execution.
