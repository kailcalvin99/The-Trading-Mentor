Mission:
Build a stable mentor-led trading platform.

Core Rules:

- Make the smallest safe change possible.
- Read existing code before editing.
- Preserve the current dark theme with emerald accents.
- Web version is the source of truth.
- Explain what changed after completing work.
- List every modified file after completing work.

- Pro = TradingView integration workflow.

When uncertain:
